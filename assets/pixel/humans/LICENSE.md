## Using the sheet

The PNG is 576×32, consisting of eighteen 32×32 frames in one row. Source rectangle for frame `n`: `(n*32, 0, 32, 32)`.

Visual inspection suggests frames 0–1 for idle, 2–9 for walking and 10–17 for the arms-forward variation. These names are integration mappings, not clip names supplied by the author. There is no separately labelled jump animation. Frame8 can be reused as an airborne pose, clearly identified as a game design decision.

Frame0 alpha bounds: left7, top0, right25 exclusive, bottom31 exclusive. A convenient foot anchor is (16,31). The sheet already has a one-pixel black outline. Gray suit colors and the cream glove/boot colors can be recolored while preserving the blue visor and black contour; exact palette values are in the metadata.
