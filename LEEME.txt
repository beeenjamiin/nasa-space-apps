ÓRBITA: FRONTERA / VERSIÓN 6 · ASTRONAUTAS JUNIOR

JUGAR: extrae el ZIP completo. Con Python 3, abre INICIAR.bat en Windows o ejecuta python3 INICIAR.py en Linux/macOS. También puedes usar Live Server. No abras con file://.

DESPLEGAR: sube index.html, pixel-game.js y las carpetas css/, assets/ y data/ a un hosting estático.

DESARROLLAR: Node 24 o posterior. npm ci, npm test, npm run build, npm run preview. Edita src2d/, data/, css/ y pixel.html; no edites pixel-game.js.

CONTROLES: A/D caminar, espacio saltar, E usar, T traje, I/Tab mochila, C taller, J bitácora, M mapa, H indicadores. Mantén clic/F para picar. Clic derecho/B para construir. Celular: joystick izquierdo y botones de acción.

CAMPAÑA: entrenamiento en Tierra, base lunar, investigación, preparación del viaje, rover y descubrimientos en Marte y regreso a la Tierra. El viaje de regreso cierra la campaña; no es un mundo terrestre abierto.

IDIOMA: Español/English en inicio y pausa. La preferencia y la partida se guardan en este navegador.

CIENCIA: enlaces NASA en la bitácora. Mapas, tiempos, recetas, tormentas y reservas son parámetros ficticios del juego, no telemetría ni alertas actuales.
